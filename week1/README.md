## Оператори

### 1. Оператор `if`
```
if (<условие>) {
    <оператор>
}
```
 `if – запазена дума`

 `<условие> ::= <булев израз>`

 `<оператор> ::= <произволен оператор>`

 Пример: 
 ```
 if (examGrade > 3) {
    std::cout << "The student passed the exam";
 } 
```
#### 1.1 Когато операторът е един, {} могат да се пропускат

Пример:
```
If(used == true) used = false; 
```
#### 1.2 Може да имаме повече от едно условие в if, като използваме помощта на логическите оператори:

`&&` = Логическо и

`||` = Логическо или

`!` = Логическо отрицание

Примери:
```
if(examGrade >= 5.5 && examGrade <= 6.0){
    std::cout << "Excellent mark!";
}

if(examGrade < 2.0 || examGrade > 6.0){
    std::cout << "Invalid mark";
}
```
### 1.3 Ако условието ни е само проверка дали булева променлива е вярна или не, то може да напишем:
```
if(used){
    std::cout << "used variable is true";
}

if(!used){
    std::cout << "used variable is false" ;
}
```
### 2. Оператор `if/else/else if`
```
if (<условие>) {
    <оператор1>;
} else {
    <оператор2>;
}

```
`else` - запазена дума

Пример:
```
if(number % 2 == 0){
    std::cout << "The number is even";
}else{
    std::cout << "The number is odd";
}
```
#### 2.1 В тялото на условен оператор може да има друг условен оператор

Пример: 
```
if(number % 2 == 0){
    if(number % 3 == 0){
        std::cout << "The number is divisible by 6";
    }
}
```
#### 2.2 Когато едно условие може да им повече от две състояния използваме `else if`
`else if` - запазена дума

Пример:
```
if(examGrade < 3.0 && examGrade >= 2.0){
    std::cout << "Student didn't pass the exam";
}else if(examGrade < 6.0){
    std::cout << "Student passed the exam";
}else if (examGrade == 6.0){
    std::cout << "Student passed the exam with perfect grade";
}else{
    std::cout << "Invalid exam grade";
}
```
### 3 Тернарен оператор
`(<условие>) ? <оператор1> : <оператор2>`

Пример:
```
int a = 6;
int b = 7;
int max = (a > b) ? a : b; 
```

### 4 Оператор switch
```
switch(<израз>) {
    case <израз1> : <редица от оператори 1>
    case <израз2> : <редица от оператори 2>
...
[default: <редица от оператори n>]опц
}

```
`switch/case/break` - запазени дума

`break` – прекратява изпълнението на най-вътрешния,
съдържащ го оператор `switch` или оператор за цикъл.

Примери: 
```
 switch(val){
        case(1):
            std::cout << '1';
            break;
        case(2):
            std::cout << '2';
            break;
        case(3):
            std::cout << '3';
            break;
        default: std::cout << '0';
    }
```

## Цикли

### 1. `for`
```
for(<инициализация>; <условие>; <корекция>) {
    <оператори>
}
```
`for` - запазена дума

Пример:
```
for(int i = 0; i < 10; ++i ){
    std::cout << i << " ";
}
```

### 2. `while`
`while` - запазена дума

Пример:
```
int i = 0;
while(i < 10){
    std::cout << i << " ";
    ++i;
}
```
### 3. `do/while`
`do/while` - запазени думи

Пример:
```
int i = 0;
do{
    std::cout << i << " ";
}while(i < 10);
```
